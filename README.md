EduPro Learner Demographics and Course Enrollment Analysis

Project Overview

This project analyses learner demographics and course enrollment behaviour on the EduPro online learning platform.

Technologies Used

* Python
* Pandas
* Streamlit
* Microsoft Excel

Features

* Analysis of learner age groups and gender
* Course category and course level analysis
* Paid and free enrollment analysis
* Monthly enrollment trend
* Interactive dashboard with filters and charts

How to Run the Project

1. Install Python.
2. Install the required packages:
   `pip install streamlit pandas openpyxl`
3. Keep `EduProapp.py` and the Excel dataset in the correct locations expected by the code.
4. Run the application:
   `streamlit run EduProapp.py`

Project Purpose

The purpose of this project is to understand enrollment patterns and present the findings through an interactive dashboard.
